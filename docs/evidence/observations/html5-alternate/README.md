# Bomb It 5 — gameplay evidence revision

Start with the report in `report/`, then the four actual-gameplay clips in `runtime/html5-alternate/recordings/`. Extract both ZIPs into the same folder. Core contains reports, selected screenshots and clips; Supporting Frames contains the uncropped source samples for the clips.

## Two separate evidence authorities
- Exact publisher v1.6.1 SWF: hash verified, static code/configuration findings and menu captures. Gameplay could not run in the attempted emulators.
- Y8/GameDistribution HTML5 alternate: directly played. Captures show bombs, explosions, death, failed results, a one-enemy victory and next-level progression. No equivalence to the SWF is established.

The first observed board and a separate near-opening board have visual transcriptions with uncertainty markers. Neither is certified simulation tick zero. The approximate visual symbol grids are not validated collision maps. Clips visualize sampled screenshots at recorded timestamp intervals, not full-rate recordings; their encoding rate is not game FPS.

## Important remaining gaps
Exact SWF runtime parity, untouched starting state, simultaneous-key priority, bomb hold/release semantics, general blocking/chain rules, all requested special-item controls and achieved FPS remain unverified. These are not invented in the report.

No implementation was changed. All images and media are reference-only and must not enter the Douyin release. No game binaries, extracted artwork/audio assets or full decompiled source are bundled. The original input documents retain repository links to files not supplied here. Capture chronology may mention exploratory frames omitted from this compact pack; delivered clip source frames and selected stills are retained.
