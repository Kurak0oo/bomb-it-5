# Edition 5 as the rules authority

The project starts independently from the parked bomb-it-1 port because that port's implementation and parity tests describe a different game. Reusing its rules would make the wrong edition authoritative. The accepted choice is to recover retail edition 5 behavior, accepting delayed implementation where evidence is missing instead of filling gaps from other editions or portal descriptions.

This record captures the rationale already present in DESIGN.md when documentation was reorganized on 2026-10-16. The current source and reuse boundaries remain in [DESIGN.md](../../DESIGN.md); this ADR is not evidence of any specific SWF behavior.
