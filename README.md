# Bomb It 5

Landscape phone game. The match rules come from the original Q版泡泡堂5 (edition 5) SWF. The pictures, names, and audio in a Douyin build are original. This is not the [bomb-it-1](https://github.com/Kurak0oo/bomb-it-1) repo, and that repo stays parked.

Open `project.godot` in **Godot 4.5** with the Compatibility renderer. Douyin's Godot exporter opens 4.5 only. Do not upgrade the project to 4.7.

The design and the two questions still open are in [DESIGN.md](DESIGN.md). An agent continuing the work starts at [AGENTS.md](AGENTS.md).
